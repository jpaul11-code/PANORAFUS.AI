# PANORAFUS.AI

A modern React + Vite application with a reusable Tailwind CSS modal system.

## Features

- Provider-driven modal control from anywhere in the app
- Smooth fade-in and slide-up modal transitions
- Backdrop click, close button, Escape key, and programmatic close support
- Custom header, body, and footer content per modal
- Responsive layout for mobile and desktop
- Multiple independently controlled modals

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` - start the local development server
- `npm run build` - create a production build
- `npm run lint` - run oxlint
