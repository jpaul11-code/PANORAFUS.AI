# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-26

### Added
- Initial release of PANORAFUS.AI
- Provider-driven modal control system for React applications
- Smooth fade-in and slide-up modal transitions
- Multiple interaction methods: backdrop click, close button, Escape key, and programmatic close
- Support for custom header, body, and footer content per modal
- Responsive design for mobile and desktop devices
- Multiple independently controlled modals
- React 19.2.8 and Vite 8.2.0 integration
- Tailwind CSS 4.3.3 for styling
- TypeScript support
- oxlint for code quality
- Development and production build scripts
